Grouping and naming continuations: what changed, and which change matters

1 · Four ways to group and name the same continuations

Each step changes one thing. A → B: only the reading of the music (key, chords, melody vs accompaniment) changes; the clustering method and the Qwen prompt stay the same. B → C: only the grouping changes (distance clusters → groups defined by musical facts), with the same Qwen prompt. C → D: only the naming changes (Qwen → names written from each group's definition). Every claim a name or description makes (a chord, "busier", "higher", "reuses P3", "melody rises", …) is checked against every member of the group, using the corrected readings.

2 · Listen and compare

One prefix at a time: its 256 one-bar continuations from AMT, grouped and named by each approach. Click a point or a sample to hear the last prefix bar followed by that continuation. The panel under the map shows the group of the selected sample under every approach. Claim chips: true for ≥ 60% of the group and ≥ 20 points more than in the other groups · true but not distinctive · false for most members; the percentage is the share of members for which the claim holds. Grey chips show what the members actually do.
